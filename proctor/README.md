# Прокторинг

[Последовательная инструкция установки и запуска](../README.md).

```powershell
python -m proctor --perf auto
```

Обычный запуск требует Windows/admin и настроенного пароля выхода; защита обязательна. Затем камера, обязательная калибровка и наблюдение. Учебных заданий и редактора вопросов нет.

Техническая проверка без защиты: `python -m proctor --preview --perf weak`.

Дополнительная панель на том же компьютере:

```powershell
python -m proctor.monitor
```
