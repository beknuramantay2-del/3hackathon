# Прокторинг

[Последовательная инструкция установки и запуска](../README.md).

```powershell
python -m proctor --perf auto
```

Сначала камера и обязательная калибровка, затем наблюдение. Учебных заданий и редактора вопросов нет.

Дополнительная панель на том же компьютере:

```powershell
python -m proctor.monitor
```
