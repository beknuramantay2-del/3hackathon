# Proctor MVP — Case 3, Qostanai Industry Hackathon
Локальный прокторинг: YOLO (телефон) + MediaPipe Face Mesh (взгляд/голова) + Guard (клавиши/фокус/процессы) + HTML-отчёт.

## Системные требования

**Python:** 3.10–3.11 (рекомендуется), минимум 3.8 (MediaPipe Face Mesh может работать нестабильно на 3.8).

**ОС:** Windows 10/11 (полная поддержка).

**Linux/macOS:** частичная поддержка. Блокировка клавиш и фокуса работают в режиме мониторинга и логирования попыток, без полной защиты (требует root/admin). Детекция телефона и взгляда работает полностью.

**Железо:** камера 720p+, процессор i5-2015+, 4GB RAM.

## Запуск
```
pip install -r proctor/requirements.txt   # Python 3.10-3.11
python proctor/tools/fetch_weights.py     # веса в proctor/weights для офлайна
python proctor/tools/set_password.py      # пароль экзаменатора (соль+хеш в config)
python proctor/main.py --profile dev      # разработка и демо: заглушка dev/stub.html
python proctor/main.py --profile exam     # боевой: требует test_url и пароль в конфиге
python proctor/main.py --demo             # процессы только логируются
python proctor/main.py --no-guard         # разработка без блокировок
python proctor/main.py --video demo.mp4   # запасное видео если нет камеры
python proctor/main.py --debug            # debug-оверлей yaw/pitch/faces/conf
python proctor/tests/test_rules.py        # синтетические тесты без камеры
python proctor/tests/test_trust.py        # индекс доверия: потолок, повторы, разбивка
python proctor/tests/test_hash.py         # цепочка хешей: запись, проверка, подмена
python proctor/tests/test_preflight.py    # эвристика виртуальной камеры
python proctor/tools/benchmark.py --seconds 30  # реальные FPS (Фаза 0)
python proctor/tools/replay_evaluator.py --video attack_phone.mp4 --gt ground_truth.json --output metrics.json
```
Аварийный выход: `Ctrl+Shift+F12`. Debug-оверлей: yaw/pitch/faces/conf в боковой панели.

## Интерфейс (строгий, офлайн)
- `proctor/ui/style.qss` — единый стиль PyQt6: #F5F5F5/#FFFFFF/#CCCCCC, акцент #2B579A.
- Старт: поле ФИО, кнопка «Начать калибровку», строка статуса камеры.
- Калибровка: точка, «Смотрите на точку», счётчик, «Отмена».
- Тест: окно теста + превью 240x180 в правом нижнем углу + одна строка статуса.
- Экзаменатор: HTTP-панель на 127.0.0.1:8901 (события, индекс, кнопка завершения). Host/port в конфиге, только локальный адрес.
- Второй монитор блокирует старт («Отключите второй монитор»), снятие — паролем экзаменатора.
- Отчёт: `data/report.html` — та же таблица + строка «Итого». Шаблон: `proctor/report/template.html`.

## Демо 3 мин (прогнать 10 раз)
1. Телефон перед экраном → PHONE_DETECTED → поднять к лицу → PHONE_RAISED → держать 2с → PHONE_AIMED
2. Взгляд вниз 3с → GAZE_DOWN
3. Взгляд вбок 2с → GAZE_LEFT/RIGHT
4. Второй человек → MULTI_FACE
5. Alt+Tab → HOTKEY_BLOCKED + FOCUS_LOST
6. Завершить тест → HTML-отчёт с индексом доверия

## Индекс доверия, целостность, replay
- Индекс доверия: старт 100, списание severity×вес из `trust_weights`, повтор типа в 5 с — вес 0.3x, потолок 50 на тип. Отчёт показывает индекс и разбивку.
- Целостность лога: каждое событие хеширует предыдущее (sha256 + отдельная соль `hash_chain.salt_hex`, генерируется при первом старте). Отчёт показывает «Целостность лога: OK/ОШИБКА».
- Pre-flight: эвристика виртуальной камеры по имени устройства (слова из `preflight.virtual_keywords`). Неизвестное имя не блокирует.
- Replay: разметка `[{"type": ..., "t_start": ..., "t_end": ...}]`, совпадение в окне ±0.5 с. Видео (honest/attack) и разметка готовятся вручную 5–8 октября.

## Честные границы (сказать жюри)
- Камера видит тыльную сторону телефона: «наведение» = положение+удержание, косвенно.
- YOLO в COCO не имеет класса «лицо»: лица — Face Mesh, person из YOLO — второй источник для MULTI_FACE.
- Ctrl+Alt+Del / Win+L не блокируются на уровне приложения — ловим потерей фокуса.
- PrtScn не блокируется гарантированно — логируем и чистим буфер.
- Взгляд грубый (центр/вниз/влево/вправо), не точка на экране.
- Эвристика виртуальной камеры ловит только совпадения имени (OBS, Droidcam и др.), записанное видео без таких слов не определяется.
- Видео не покидает компьютер.
