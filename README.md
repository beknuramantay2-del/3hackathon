# Локальный прокторинг

Камера, контроль головы и взгляда, обнаружение телефона, предупреждения и запись событий. Всё обрабатывается на компьютере. В приложении **нет учебных заданий, редактора вопросов или проверки ответов** — это самостоятельный инструмент наблюдения.

Основной экран сразу показывает большую камеру. Голова и глаза отображаются отдельно, обнаруженные объекты подсвечиваются. Дополнительная панель позволяет наблюдать за сессиями на том же компьютере.

## 1. Подготовить окружение

Нужны **Python 3.11**, веб-камера и интернет для первой установки. Запустите PowerShell из папки проекта:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
.venv\Scripts\python.exe -m pip install -r proctor/requirements.txt
.venv\Scripts\python.exe -m proctor.tools.fetch_weights
```

Загрузчик подготовит две модели: `yolov8n.pt` и `yolov8s.pt`. После этого интернет для наблюдения не нужен. CUDA и отдельная видеокарта не обязательны.

На Linux создайте окружение той же командой, затем используйте `.venv/bin/python` вместо `.venv\Scripts\python.exe`. Для Qt нужны системные библиотеки GL/EGL и XKB.

## 2. Открыть прокторинг

На Windows после установки достаточно открыть **`start.bat`**. Либо выполнить:

```powershell
.venv\Scripts\python.exe -m proctor --perf auto
```

Камера открывается сразу. Не нужны аккаунт, импорт вопросов или подготовка учебного материала. По умолчанию работает режим просмотра: он не блокирует клавиши и другие окна.

Для слабого ноутбука:

```powershell
.venv\Scripts\python.exe -m proctor --perf weak
```

Если камер несколько, измените `camera.index` в `proctor/config.yaml`. Закройте программы, которые уже используют камеру. При отсутствии моделей приложение покажет ошибку; повторите команду загрузки весов из первого шага.

## 3. Пройти обязательную калибровку

Сядьте перед камерой, обеспечьте освещение лица и дождитесь загрузки моделей. Настройка начнётся автоматически после обнаружения одного лица.

**30 секунд:** сначала пять положений головы, затем пять направлений глаз с прямой головой. Следуйте подсказкам и точке на экране. Не поворачивайте голову на этапе глаз. Если измерения не приняты, исправьте положение/свет и нажмите «Настроить взгляд» повторно.

До успешного завершения направления могут отображаться как предварительные, но тревоги по отводу головы/глаз не включаются. Нечитаемый взгляд показывается как «Не определяется», а не как выдуманное направление. Обнаружение телефона не зависит от завершения калибровки.

## 4. Посмотреть работу

Проверяйте движения последовательно, возвращаясь в центр между ними:

1. Смотрите прямо: проверьте наличие лица и независимые состояния головы и глаз.
2. Поверните только голову влево, вправо, вверх и вниз.
3. С прямой головой переведите только глаза в те же направления.
4. Задержите взгляд вниз или в сторону: видны направление, длительность и сигнал.
5. Покажите телефон полностью, затем частично у нижнего края. Проверьте рамку и предупреждение; уберите телефон.
6. Поднимите телефон к экрану. Подъём и возможное наведение фиксируются как наблюдения.
7. Выйдите из кадра, вернитесь и попросите второго человека появиться рядом.

**Сигналы:** зелёный — нет активной тревоги; жёлтый — удержание подозрительного направления от 3 с; красный — от 5 с. Телефон даёт красный сигнал после первого надёжного результата или подтверждения tracking. Один слабый кандидат не считается доказанным телефоном. Возврат в центр сбрасывает удержание, краткий шум не должен создавать отдельную тревогу.

Показатели FPS, времени обработки, возраста данных и памяти измеряются в работающем приложении. Confidence — оценка модели, **не процент точности**. Действительную точность оценивайте по наблюдаемому движению, а не по красивым цифрам.

## 5. Открыть панель наблюдения — по желанию

Оставьте основное приложение открытым. Во втором терминале:

```powershell
.venv\Scripts\python.exe -m proctor.monitor
```

Выберите сессию слева. Видны кадр с подсветкой, голова, глаза, лица, телефон и журнал сигналов. Панель обновляет данные раз в секунду, получает JPEG до 2 раз/с и **не запускает распознавание повторно**. После 3 с без свежего кадра изображение убирается: старый кадр не выдаётся за live.

Для именной сессии основное приложение можно запустить так:

```powershell
.venv\Scripts\python.exe -m proctor --name "Имя ученика" --perf auto
```

Панель работает только на том же компьютере. Она не является сетевым сервером для класса и не защищает файлы от владельца учётной записи ОС. В защищённом режиме не переключайтесь на панель: потеря фокуса сама является наблюдаемым событием.

## 6. Завершить и посмотреть запись

Дважды нажмите на событие в основном окне, чтобы открыть его футаж. Подождите несколько секунд после события: запись включает до 2 с до и после него. Затем нажмите **«Завершить и сохранить»**.

Каждая сессия находится в `data/sessions/<дата_и_время>/`: SQLite с событиями, снимки, видеофрагменты и настройки калибровки. Аудио и рабочий стол не записываются. Перед использованием с учениками получите согласие на запись и установите срок хранения данных.

## Защита рабочего окружения — отдельно

Для первого знакомства используйте обычный просмотр. Защита требует **Windows и терминал с правами администратора**. Сначала настройте пароль выхода:

```powershell
.venv\Scripts\python.exe -m proctor.tools.set_password
.venv\Scripts\python.exe -m proctor --protected --perf weak
```

Включаются hooks клавиш, контроль фокуса/процессов и буфера обмена. Ctrl+Shift+F12 вызывает выход по паролю. Сохраните работу в других программах до включения защиты.

Это прикладная защита, **не системный kiosk**. Встроенного браузера нет, поэтому не заявляется контроль вкладок произвольного внешнего браузера. Физические блокировки Windows требуют проверки на конкретном компьютере.

## Производительность и ограничения

Общий кадр проверяет YOLOv8n; более сильная YOLOv8s обрабатывает только дополнительный ROI. Максимум два прохода на обработанный кадр, до 4 обработок/с для объектов; голова/глаза работают отдельно. Latest-frame workers не накапливают очередь старых кадров. `auto` выбирает бюджет по CPU/RAM, `weak` уменьшает нагрузку. Панель и запись работают отдельно от inference.

Ориентир слабой конфигурации — **i5‑4200M, 8 ГБ RAM**, но подтверждённый FPS на этой машине не заявляется. [Измерения CV и ограничения](proctor/docs/PHONE_DETECTION.md).

Частично закрытый телефон, очки, плохой свет и крупный поворот головы могут ухудшать распознавание. «Возможное наведение» — эвристика положения телефона, не доказательство направления его объектива или намерения фотографировать. Предупреждения помогают человеку проверить ситуацию, а не автоматически обвиняют ученика.
